# Міграція з v7 до вебверсії v8

v7 — локальний Python/SQLite; v8 — Cloudflare Worker/D1. Фізично це різні бази, тому зберігайте backup v7 до підтвердження міграції.

## Найпростіше без Python

1. Запустіть стару v7 у вас, якщо вона вже встановлена, і експортуйте **повний каталог `schedule_rules.csv`** через панель.
2. Відкрийте v8 у браузері, вкладка **«Авіарозклади»**, блок **«Перенесення бази з v7»**.
3. Виберіть CSV та натисніть **«Імпортувати CSV з v7»**.
4. Подивіться `added`, `updated`, `rejected_count`. Якщо частина рядків відхилена, перевірте `weekdays_json`, `flight`, `airline`, `origin`, `destination`, `departure_time`.
5. Повторний імпорт ідентичного CSV **не дублює** записи.

**Обмеження:** один HTTP-імпорт — до 2500 рядків і до 1,2 MB JSON; розбийте більший експорт на частини. Це переносить регулярні правила. Історія первинних raw JSON відповідей, приватні .env ключі, `schedule_revisions` v7 і старі flight instances автоматично **не** переносяться. Збережіть вихідну SQLite як архів.

Якщо у v7 немає заповненої бази, цей крок просто пропустіть: v8 збере новий каталог через API.
