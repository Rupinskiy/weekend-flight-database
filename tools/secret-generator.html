Генератор Cloudflare Secrets

Ця сторінка працює офлайн на вашому комп'ютері. Немає запитів до серверів або зовнішніх бібліотек. Випадкові значення створюються криптографічним генератором вашого браузера.

Скопіюйте значення в Cloudflare Worker → Settings → Variables and Secrets як тип Secret.

Збережіть копію цього секрету у власному менеджері паролів. Його зміна пізніше зробить уже зашифровані API-ключі непридатними до читання.

Це пароль входу у вебпанель Weekend Flight Database.

Для копіювання клацніть у поле (значення виділиться повністю), натисніть Ctrl+C. Не надсилайте ці значення у GitHub, чати чи електронну пошту. Закрийте вкладку після збереження.
